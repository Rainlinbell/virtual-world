# 虚拟世界模拟器 — 实现计划

## Context（背景）

用户需要一个"虚拟世界"项目：在 Web 管理界面上定义世界观、剧情大纲和主要人物，之后由 AI 运算推进世界线（生成下一阶段叙事、更新人物状态与世界时间）。本地运行、无需登录、UI 全中文。

项目目录 `d:\Develop\virtual world` 为空，全新搭建。本机 Node v24（满足内置 fetch）。

## 技术选型

- **后端**：Node.js + Express（唯一依赖），`server.requestTimeout = 0`（推进是长请求，Node 18+ 默认 300s 会掐断）
- **存储**：JSON 文件。每个世界一个文件（含世界观/人物/大纲/编年史全量），原子写（tmp+rename）；`data/backups/` 每次推进前快照，保留最近 10 份
- **前端**：无构建步骤的原生 HTML/CSS/JS，hash 路由 SPA，Express 静态托管
- **AI**：OpenAI 兼容 `/chat/completions` 客户端，设置页可配置 baseUrl / apiKey / model / temperature（兼容 GLM、DeepSeek、OpenAI、本地 Ollama；apiKey 为空不发 Authorization 头）。不用 `response_format`，靠 prompt 纪律 + 解析容错

## 数据模型（要点）

```ts

           advance: { recentTimelineCount=20, maxRetries=1 } }
```

## REST API

错误统一 `{ error: "中文信息" }`；404 不存在 / 400 缺参数 / 409 推进中 / 502 AI 失败（附原始输出摘录）。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/PUT | `/api/settings` | 读取/合并保存设置 |
| POST | `/api/settings/test` | 测连通（GET /models，返回 ok/延迟/modelExists） |
| GET/POST | `/api/worlds` | 列表摘要 / 创建 `{name, worldview?}` |
| GET/PUT/DELETE | `/api/worlds/:id` | 全量详情 / 改名改世界观 / 删除 |
| POST | `/api/worlds/:id/advance` | `{directorNote?}` 同步长请求，返回 `{entry, worldFile}` |
| POST | `/api/worlds/:id/characters` · PUT/DELETE `/:cid` | 人物增改删（手动纠正 AI 结果的入口） |
| POST | `/api/worlds/:id/outline` · PUT/DELETE `/:nid` | 大纲增改删 |

编年史不设写接口（不可变，靠备份兜底）。

## AI 推进引擎（核心）

**System prompt 要点**：你是叙事引擎 GM；严格符合世界观、延续历史、尊重人物既有事实；有导演指令则优先执行；中文第三人称 800~1500 字；**只输出一个合法 JSON 对象**，字段：

```json
{ "narrative", "events": [], "timeAdvanced", "worldTime", "worldStatus",
  "characterUpdates": [{ "id?", "name", "alive?", "condition?", "location?", "abilities?", "notes?" }],
  "newCharacters": [{ "name", "role?", "description?", "condition?", "location?" }],
  "outlineUpdate": { "completedNodeId?", "currentNodeId?" } }
```

**用户消息组装**：世界观 → 大纲（带 id+状态标记）→ 人物当前状态（带 id）→ 编年史概要（最近 N 条，仅 seq/时间/events）→ 上一次叙事全文 → 导演指令。

**解析容错**：直接 parse → 剥围栏/截取 `{...}` → 类型矫正（narrative 非空必填）→ 失败重试 1 次（附错误提示）→ 仍失败 502。

**合并逻辑**：内存锁（防 409 重入）→ 备份快照 → 人物更新先按 id 后按 name 匹配（未命中记入 warnings）→ timeline 追加、currentState 更新、大纲节点状态流转、新人物生成 id → 原子写盘。中途失败不落库。

## 前端页面

- `#/worlds` 世界列表：卡片网格（世界名/世界时间/局势/人物数/推进次数）+ 创建 modal + 删除
- `#/worlds/:id?tab=...` 详情页：头部（世界名、当前时间、**「推进世界线」主按钮**）+ 5 个 tab
  - **总览**：局势 + 人物速览 + 最新叙事 + 空世界三步引导
  - **世界观**：大文本域编辑
  - **人物**：卡片 + 增改删 modal
  - **大纲**：节点列表（状态徽标点击循环切换、编辑、删除）
  - **编年史**：倒序时间线（seq/世界时间/事件/人物变化/导演指令/警告/叙事，最新展开其余折叠）
- `#/settings` 设置页：AI 表单 + 「测试连通性」（先测后存）

推进流程：点击 → 导演指令 modal（可空）→ 全页遮罩 spinner（"AI 推演中…"）→ 成功刷新并展示新叙事 / 失败 toast 显示错误。未配置 AI 时引导跳设置页。

## 实施步骤（每步可验证）
